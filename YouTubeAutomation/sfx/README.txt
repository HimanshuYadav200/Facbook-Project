# Sound Effects Configuration
# Place your sound effect files in this directory.
# The EditorAgent will use these files based on keyword matching.
#
# Recommended files (MP3 or WAV, short duration 0.5-2 seconds):
# - whoosh.mp3       : Transition sounds
# - coin.mp3         : Money/financial keywords ($, earn, profit, invest)
# - impact.mp3       : Dramatic moments (crash, fail, lost)
# - notification.mp3 : Alert/news sounds (breaking, urgent)
# - success.mp3      : Positive outcomes (win, grow, success)
#
# Tips for best results:
# - Keep sounds short (0.5-2 seconds max)
# - Use sounds without background music (clean FX only)
# - Lower bitrate is fine (128kbps MP3)
#
# The system will automatically lower the volume of SFX
# to avoid drowning out the narration.
