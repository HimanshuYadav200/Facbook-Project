# Topic bank: stickman-money

100 story seeds. Each is a **seed, not a script**: write a fresh story from it (our own characters, setting, words).
Mark a used seed with `[x]` and the run id. Pick seeds so the same formula doesn't run 3 times in a row.

**Formulas** (see SKILL.md): **A** two people, same start · **B** parent/elder and child · **C** "you" truth · **D** stages/signs.
**Inspiration** = where the idea comes from. Fables are public domain (Project Gutenberg: Aesop, Panchatantra, Jataka, Tolstoy, Nasreddin); we borrow the *shape*, never the text. Psychology ideas are well-known concepts (OpenStax *Psychology 2e*, behavioural economics); name them only if we can source them.
**Stat?** = the story could carry one real number; fetch and source it with the finance tools before using it (never from memory).
